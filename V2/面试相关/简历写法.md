HarnessPRD 是 AI 驱动的需求文档流水线，帮助用户将模糊想法整理为 PRD、接口文档及 AI 开发工具可用的提示词套件。项目打通「结构化录入 → 澄清对话 → 摘要差异确认 → 多 Agent 生成 → 人工审核」全链路，支持方案断点恢复与文档版本追溯。基于 FastAPI + React + LangChain 实现；文档生成采用后台 Job + SSE 重连，团队规范经 Skill 知识层注入，并具备 Token 预算管控与分步运行观测。

个人职责
- 全流程架构与核心开发：负责前后端整体架构与主链路实现，覆盖从需求录入、澄清对话、文档生成、人工审核到交付导出的完整闭环；后端按对话、生成、任务、持久化分层拆分。

- 流式交互与后台生成任务：负责澄清 SSE 与文档生成 Job 两套流式协议；前端多阶段状态机、生成进度展示，以及刷新后的任务重连与进度恢复。

- 多 Agent 生成链路：负责 Writer / Reviewer / Rewriter 三个 Agent 流水线的设计与实现，覆盖 PRD 起草、审查与定向修订，并与后台生成任务、流式进度推送衔接。

- 规范注入与多模型接入：负责 Skill 知识层注入与三类文档 Prompt 拼装；基于 LangChain 统一封装多模型，支持流式调用与配置管理。


6. 可靠性配套（可选，篇幅紧可合并进第 2 条）
负责 Token 预算检查、分步运行观测、生成前门禁与结构校验、方案快照持久化等横切能力。



难点亮点
- 非结构化对话难稳定沉淀为可生成输入：设计结构化摘要方案——表单录入后经澄清对话回填 JSON；前端依托 Diff 面板逐字段展示变更，用户确认后再触发 PRD，形成「录入 → 澄清 → 回填 → 差异确认 → 生成」闭环。
- 一次性生成 PRD 易缺章漏项：基于 Writer / Reviewer / Rewrite 双 Agent 链路优化 PRD 生成——Writer 流式起草，Reviewer 输出结构化审查结论，未通过则按意见修订；前端通过 SSE 流式输出同步展示各阶段进度。
- 接口文档生成缺乏团队规范约束：在接口文档阶段接入本地轻量 RAG，注入团队规范与历史 API 示例；生成前展示命中片段供用户确认，提升输出规范性与贴合度。
- 大模型结构化输出存在格式漂移：针对摘要回填、审查结果等 JSON 链路，设计「提取 → 修复 → 重试」三级兜底，降低因格式错误导致的流程中断。
- 澄清对话与文档生成职责易混淆：为澄清阶段单独约束 System Prompt，将「需求收集」与「文档产出」阶段解耦，减少模型越界生成导致的流程失控。
