# 产品入口与需求采集重塑 — 测试验收

## 测试准备

验收范围：

- 路径选择页与导入向导（主路径 / 导入 PRD / 导入 PRD+接口文档）
- 结构化表单列表编辑器与行业模板
- 产出物进度条与 PRD 审阅页 CTA 分层

环境要求：

- `backend/.env` 配好 LLM
- 后端 `uvicorn main:app --reload` 已启动
- 前端 `npm run dev` 已启动
- 浏览器可访问 `/v2` 与 `/v2/list`

**不在本次验收范围：** v1 `/` 旧版、澄清 Job 化、RAG 删除、文档过期提示、导出 ZIP、版本 diff。

---

## 一、路径选择页

### 1. 新建方案默认页

1. 打开 `/v2`（无 session id）

预期：

1. 看到 **路径选择页**，有「从零创建 PRD」与「导入已有素材」两类入口
2. **没有** 原来的三 Tab（从零开始 / 从 PRD 开始 / 从提示词开始）
3. **没有** JSON 预览按钮

### 2. 主路径进入与返回

1. 点「从零创建 PRD」
2. 点「← 返回路径选择」

预期：

1. 进入结构化表单，字段区块正常
2. 返回后回到路径选择页，未创建 session 时不报错
3. 表单内容若已填写，返回再进入可保留（同页 state）或按实现约定清空——文档需一致即可

### 3. 导入 PRD

1. 在路径选择页进入「我有 PRD」
2. 粘贴一段测试 PRD
3. 点「进入 PRD 环节」

预期：

1. 进入 `review-prd`，正文为粘贴内容
2. `SessionList` 中该方案入口标签为 **「导入 PRD」**（或等价新文案）
3. 「直接生成接口文档」仍可用（行为与改前一致）

### 4. 导入 PRD + 接口文档

1. 进入「我有 PRD + 接口文档」
2. 填写 PRD，接口文档可留空或填写
3. 点「直接生成提示词」

预期：

1. 进入提示词生成流程
2. 列表入口标签为 **「导入 PRD+接口文档」**

### 5. 老方案加载

1. 在列表打开改前创建的 `structured` / `prd` / `prompts` 方案

预期：

1. **不** 强制经过路径选择页
2. 落在对应表单子界面或审阅页，数据不丢

## 二、结构化表单

### 1. MVP 功能列表

1. 主路径表单 → 「+ 添加功能」添加至少 2 行
2. 删除一行
3. 不填 MVP 直接点「开始澄清对话」

预期：

1. 每行独立输入名称、描述、价值，**无** 管道符格式说明
2. 删除后行数变化正确
3. 校验失败并有明确错误提示（至少一个 MVP）

### 2. 页面结构列表

1. 添加页面行，模块用逗号分隔
2. 留空页面名提交

预期：

1. 列表编辑正常
2. 空页面名校验失败

### 3. 无 JSON 预览

预期：结构化表单区域 **全程无**「查看 JSON 预览」按钮和 `requirements_summary` 代码块。

### 4. 行业模板

1. 打开模板选择器
2. 依次应用「内部审批流」「内容社区」「AI 助手」中至少 2 个
3. 应用前确认覆盖

预期：

1. 表单被填充，MVP 与页面为列表行而非管道符字符串
2. 应用「朋友圈文案助手」与改前示例等价（可生成 PRD）
3. 覆盖前有确认提示

### 5. 老 Session 迁移

1. 用改前保存的、含管道符 `mvp_features` 字符串的 Session（若无则手动在 DB / save API 写入旧格式）
2. 打开该方案

预期：MVP、页面显示为多行编辑器，内容语义正确。

### 6. 澄清回填

1. 填表 → 澄清若干轮 → 触发 summary diff（若对话改动了摘要）→ 确认应用

预期：表单列表与确认后的 `requirementsSummary` 一致，无管道符中间态。

## 三、主路径全流程（产出物 + CTA）

1. 从零创建 → 填表（可用模板）→ 澄清 → 生成 PRD → 审阅 PRD

### 1. 顶栏产出物

预期：

1. 左侧文案为 **「产出物」**
2. 依次出现：需求、澄清、PRD、接口文档、提示词（5 个）
3. 澄清完成后「需求」「澄清」为已完成态
4. PRD 生成后为已完成，当前在 PRD 为进行中/已完成

### 2. PRD 审阅 CTA（主路径）

在 `review-prd`，`entryMode === 'structured'`：

预期：

1. **主按钮**只有一个深色「生成接口文档 →」
2. 「跳过接口文档，直接生成提示词」为次要样式（小字/链接），**不是**与主按钮同大的 secondary
3. 点跳过 → 出现 confirm → 确认后进入提示词生成
4. 点取消 → 留在 PRD 页

### 3. 未生成节点不可点

在仅有 PRD、无接口文档时：

预期：顶栏「接口文档」「提示词」为未开始，**点击无跳转**。

### 4. 已完成节点可点

生成接口文档后：

预期：顶栏「PRD」「接口文档」可点击回到对应 `review-*` 页。

### 5. 接口文档 → 提示词

预期：`review-api-docs` 仅「生成提示词 →」为主前进按钮，流程正常完成。
