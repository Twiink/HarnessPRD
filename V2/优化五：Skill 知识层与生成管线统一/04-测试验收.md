# Skill 知识层与生成管线统一 — 测试验收

## 测试准备

验收范围：

- Skill 契约、`config/skills.yaml`、`skill_loader`
- `api-docs-generator`、`prompts-generator`
- RAG 下线（后端 + 前端）
- `run_summary.injected_skills`

环境要求：

- `backend/.env` 配好 LLM
- 后端 `uvicorn main:app --reload` 已启动
- 前端 `npm run dev` 已启动
- 浏览器可访问 `/v2` 与 `/v2/list`

**不在本次验收范围：** `team.yaml`、规范上传 UI、Skill 版本 pin、向量 RAG、澄清 Job 化、文档 diff / 导出、v1 `/`。

---

## 一、Skill 基础设施（01 篇）

### 1. 目录与配置

检查仓库：

1. `skills/prd-generator/skill.yaml` 存在
2. `config/skills.yaml` 存在
3. `backend/services/skill_loader.py` 存在

预期：

- `prd` 绑定 `prd-generator`
- `skill.yaml` 的 `id` 与目录名一致

### 2. Loader 加载

在后端 REPL 或临时脚本：

```python
from services.skill_loader import load_skill_bundle, compose_prompt_sections
bundle = load_skill_bundle("prd")
sections = compose_prompt_sections(bundle)
```

预期：

- `bundle.skills == ["prd-generator"]`
- `sections` 含 `template`、`schema`（或等价 key）
- 无异常

### 3. PRD 生成回归

1. 主路径：填表 → 澄清 → 生成 PRD

预期：

- PRD 章节结构完整（概述、功能表、技术规格等）
- MVP 为表格
- 与改前风格可比，无明显退化

### 4. 摘要回填

1. 澄清中补充明确信息 → 触发 summary sync / diff 确认

预期：

- 回填 JSON 合法
- `field-schema` 约束仍生效

## 三、RAG 下线 — 前端

### 1. 无确认页

1. 主路径走完 PRD 审阅
2. 点「生成接口文档 →」

预期：

1. **立即** 进入 `generating-api-docs`（版本侧栏显示生成中）
2. **不出现**「生成接口文档前 · 确认参考资料」页
3. **不出现**「找到 N 段资料」列表
4. 浏览器网络：**无** `POST .../retrieve-api-docs-rag`

### 2. 导入路径同样无门控

1. 导入 PRD 进入审阅 → 生成接口文档

预期：同样直连 Job，无 RAG 页。

### 3. Session 字段清理

1. 打开老 Session（若曾保存 `ragHits`）

预期：加载不报错；不展示 RAG 残留 UI。

## 四、RAG 下线 — 后端与生成质量

### 1. 接口文档内容

生成完成后审阅接口文档。

预期（结合团队规范示例）：

- 路径风格接近 `/api/v1/...`
- 有统一响应结构（如 `code` / `message` / `data`）
- 非空、可读的 Markdown

### 2. 提示词生成

1. PRD → 接口文档 → 生成提示词

预期：

- 进入 `generating-prompts` 后正常完成
- 提示词套件结构完整（非单段敷衍）

### 3. 优化 Job 回归

1. 在 PRD 或接口文档页发起「优化文档」

预期：Job 正常，刷新可重连；无 RAG 相关错误。
