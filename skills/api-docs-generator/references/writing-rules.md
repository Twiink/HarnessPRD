# 接口文档写作要点

## 格式要求

1. 使用 Markdown 格式
2. 接口按「核心接口」和「边缘接口」两大类组织——核心接口是产品 MVP 的必须接口，边缘接口是辅助功能（配置、统计、管理等）
3. 每个接口包含：接口名称、HTTP Method + Path、功能说明、请求参数（表格）、响应结构（示例 JSON）
4. 路径命名遵循 RESTful 规范
5. 核心接口和边缘接口分别以 `## 核心接口` 和 `## 边缘接口` 作为二级标题

## 文档结构模板

```
# 接口文档：[产品名称]

## 核心接口

### 1. [接口名称]
- **方法**：POST / GET / PUT / DELETE
- **路径**：/api/v1/...
- **功能**：...

**请求参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| | | | |

**响应示例**
```json
{
}
```

## 边缘接口

（同上结构）

---
*由 VibeCoding 生成 · 供 AI 辅助开发使用*
```

请根据 PRD 内容设计合理的 API 接口，覆盖所有功能点。明确区分哪些是 MVP 必须接口、哪些是辅助接口。使用中文说明。
