# 提示词套件结构模板

基于产品需求文档和接口文档，生成一套完整的 AI 辅助开发提示词套件。

每个提示词必须：
- 直接可用，复制粘贴给 Claude Code 即可使用
- 包含足够的背景上下文
- 使用中文

生成以下 5 类提示词：

## 1. 项目总览提示词（Project Context Prompt）
让 AI 完整理解项目背景、技术栈、核心功能。适合在项目开始时使用，建立全局上下文。

## 2. 功能开发提示词（Feature Development Prompts）
针对每个核心功能模块，各设计一个专用提示词，引导 AI 逐步实现功能。功能数量与 PRD 中 产品功能数量一致。

## 3. 接口实现提示词（API Implementation Prompt）
引导 AI 按照接口文档实现后端逻辑，包含具体接口规范。如无接口文档则跳过此部分。

## 4. 前端开发提示词（Frontend Development Prompt）
引导 AI 实现前端界面和交互逻辑，包含设计风格要求。

## 5. 代码审查提示词（Code Review Prompt）
引导 AI 对生成代码进行质量检查，检查维度包括代码规范、安全性、性能。
