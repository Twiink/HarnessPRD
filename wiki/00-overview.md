# VibeCoding 项目概览

## 是什么

VibeCoding 是一款 AI 驱动的**对话式产品需求收集平台**。它通过结构化表单 + 自然语言对话的方式，帮助用户清晰表达软件产品需求，并自动生成可供 Claude Code 等 AI 编程工具直接使用的文档套件。

## 解决什么问题

| 痛点 | VibeCoding 的解法 |
|------|-----------------|
| 非技术用户说不清楚需求 | AI 扮演资深产品经理，通过双向对话引导用户想清楚 |
| 开发者理解需求成本高 | 自动生成结构化 PRD，消除沟通歧义 |
| AI 辅助开发缺乏上下文 | 输出与 Claude Code 兼容的提示词套件，可直接使用 |
| 接口设计反复沟通 | 根据 PRD 自动设计 RESTful API 文档，分核心/边缘接口 |

## 核心工作流

```
填写表单 → AI 对话 → 生成 PRD → 生成接口文档 → 生成 AI 提示词 → 下载
```

每个阶段用户均可：
- **审核**：查看 AI 生成的内容
- **编辑**：直接修改文档
- **优化**：输入指令要求 AI 重新优化
- **跳过**：某些阶段可跳过（如接口文档）
- **结束任务**：随时下载已有文档并结束

## 功能一览

### 1. 需求收集表单
10 个基础问题 + 5 个高级问题，覆盖产品定义的核心维度：
- 产品名称、核心问题、目标用户
- MVP 功能、v2 规划
- 页面数量、设计风格、平台类型
- 登录需求、数据存储
- 技术栈、第三方 API、安全/性能要求、部署方式

### 2. AI 对话引导
- AI 角色：资深产品经理
- 双向对话，非单向追问
- 每次聚焦 1-2 个关键点
- 适时总结，推动对话向前

### 3. 文档生成
| 文档 | 内容 |
|------|------|
| PRD | 产品需求文档（6 个标准章节） |
| 接口文档 | RESTful API 设计（核心接口 + 边缘接口） |
| AI 提示词套件 | 5 类提示词（项目上下文/功能开发/接口实现/前端开发/代码审查） |

### 4. 文档管理
- 流式输出（实时看到生成过程）
- 实时编辑（textarea 直接改）
- 一键复制
- AI 优化（自然语言指令）
- 下载（Markdown 文件）

## 适用对象

- 想用 AI 辅助开发但不知如何描述需求的**创业者/产品人**
- 需要快速出 PRD 的**产品经理**
- 想降低需求沟通成本的**开发团队**
- 学习 AI 辅助开发工作流的**学习者**

## 技术定位

VibeCoding 本身是一个轻量级的 Web 应用，后端约 1000 行 Python，前端约 1400 行 TypeScript + React。整体架构简单，便于二次开发和私有化部署。
